# Bekleyen çeviriler

Bu dosyalar henüz uygulamada değil; dil ekleme görevinde güncellenip geri alınacak.

- Diller: İspanyolca (`es`), Fransızca (`fr`), Almanca (`de`), Portekizce-Brezilya (`pt`), Rusça (`ru`), Çince Basitleştirilmiş (`zh`), İtalyanca (`it`), Endonezce (`id`).
- Geri almadan önce `lib/l10n/app_en.arb` ile karşılaştır: o tarihten sonra eklenen ya da değişen anahtarları güncelle. Bugünkü fark: bu dosyalarda dil seçici için `languageNativeName` var, uygulamada ise `languageTurkish` ve `languageEnglish` var.
- Yayından önce her dili anadili konuşan biri okumalı.
